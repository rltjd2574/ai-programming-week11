공통 규칙 (VS Code Copilot Chat 기준)
  1. Copilot Chat을 엽니다 (Ctrl+Alt+I). 실험마다 + 버튼으로 새 채팅을 시작합니다.
  2. 모드는 Ask를 고릅니다. (Agent·Edit 모드는 파일을 직접 고칠 수 있습니다)
  3. 모델은 Auto 말고 하나를 직접 고르고, 모든 실험에서 같은 모델을 씁니다.
     모델 이름을 학습지에 적습니다.
  4. 입력창 위에 붙은 파일 칩을 X로 지웁니다.
     실험 2에서는 bug3_logic.py에서 함수 6줄을 복사한 뒤 그 탭을 닫습니다.
     (코드를 선택한 채 채팅을 열면 'bug3_logic.py:41-46' 같은 칩이 붙습니다)
  5. 'Allow reading external files?' 창이 뜨면 Skip을 누릅니다.
     bug3_logic.py 위쪽 주석에는 버그 힌트가 있어, 읽게 하면 비교가 무효가 됩니다.
  6. 입력창에서 줄을 바꿀 때는 Shift+Enter. ( ) 안의 안내문은 보내지 않습니다.
  7. 답에서 'from … import …'로 시작하는 코드 블록만 복사해 정해진 파일 이름으로
     저장합니다. AI가 다른 파일 이름을 말해도 따르지 않습니다. ``` 표시는 넣지 않습니다.
     받은 코드는 고치지 않습니다. 고치고 싶으면 _fixed.py 사본을 따로 만듭니다.
